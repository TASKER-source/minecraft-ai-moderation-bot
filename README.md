# Minecraft AI Moderation Bot 🤖⛏️

An AI-powered Minecraft moderation and support bot.

## Features

- 🚨 Detect inappropriate language
- ⚠️ Warn players for rule violations
- 🔇 Temporarily mute repeated offenders
- 🛡️ Detect spam and unwanted behavior
- 🆘 Help players with server questions
- 📋 Keep moderation logs
- 👮 Notify staff about serious incidents

## Commands

- `/report <player> <reason>` — Report a player
- `/help` — Get server help
- `/rules` — View server rules
